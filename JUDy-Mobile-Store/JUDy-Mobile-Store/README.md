# JUDy Mobile Store

Smartphone e-commerce website made with **HTML5, CSS3 and JavaScript only** (data saved in LocalStorage).

## How to run
1. Open the `JUDy-Mobile-Store` folder in Visual Studio Code.
2. Right-click `index.html` -> **Open with Live Server** (or double-click `index.html` to open it in a browser).

## Login (username + password only)
- Customers: click **Register**, choose a username and password, then login.
- Admin: username `admin`, password `admin123` (use the same login page).

## Reset the demo data
DevTools (F12) -> Application -> Local Storage -> delete the `judy_*` keys, then refresh.
